# .NET Practicals — Step-by-Step Visual Studio Instructions

Welcome to the comprehensive laboratory collection of **23 complete .NET and C# programming practicals and sub-practicals**. This repository provides complete source code, academic documentation, and **dedicated step-by-step Visual Studio execution guides** created specifically for college students and instructors.

Each practical is organized in its own self-contained folder containing:
1. **Visual Studio Step-by-Step Instructions Document** (`Practical-XX-Steps.docx`) — A student-friendly, numbered Visual Studio walkthrough explaining exact clicks, Solution Explorer navigation, configuration, build, execution, verification, and troubleshooting.
2. **Academic Documentation Word Document** (`Practical-XX-Documentation.docx`) — Complete standard laboratory report covering Aim, Theory, Algorithm, Source Code, Output, and Viva Questions.
3. **Plain-Text Reference Guide** (`Practical-XX-Notes.txt`) — Terminal-friendly reference notes with complete code and instructions.
4. **Primary Source Code & Supporting Files** (`.cs`, `.aspx`, `.cshtml`, `.js`, `manifest.json`, `appsettings.json`, `Web.config`, etc.) required to build and execute the practical.
5. **Original PDF Document** ([dot net.pdf](./dot%20net.pdf)) preserved at the root of the repository.

## Software & System Requirements

Depending on the practical being executed, ensure the following components are installed:

1. **Integrated Development Environment**:
   * Visual Studio 2022 (Community, Professional, or Enterprise) or Visual Studio 2019.
   * Workloads required:
     * **.NET desktop development** (for Console applications)
     * **ASP.NET and web development** (for Web Forms, MVC, Web API, and PWAs)
2. **Frameworks & SDKs**:
   * **.NET SDK 6.0, 7.0, 8.0, 9.0, or 10.0** (Cross-platform support for Console, MVC, Web API)
   * **.NET Framework 4.7.2 or 4.8** (Required for ASP.NET Web Forms practicals 04A, 04B, 04C, 05B)
3. **Database & ORM**:
   * **SQL Server LocalDB** (included with Visual Studio) or **SQL Server Express**
   * **Entity Framework Core Tools** (`Microsoft.EntityFrameworkCore.SqlServer`, `Microsoft.EntityFrameworkCore.Design`)
4. **Browsers & Testing Tools**:
   * Google Chrome, Microsoft Edge, or Mozilla Firefox with DevTools (Application panel for Service Workers and Manifest inspection)
   * Postman or cURL CLI for Web API testing (Practicals 08B and 09A)

## Instructions for Opening and Running in Visual Studio

### 1. C# Console Applications (Practicals 01A – 03C)
1. Open **Visual Studio**.
2. Click **Create a new project**.
3. Choose **Console App (C#)** and click **Next**.
4. Set the project name (e.g., `Practical01A`) and select `.NET 8.0` or `.NET 6.0`.
5. In **Solution Explorer**, double-click `Program.cs`.
6. Open the corresponding practical code file (e.g., `Practical-01A-Code.cs`), copy its contents, and replace `Program.cs`.
7. Press **F5** (or click the green **Play** button / **Debug &rarr; Start Debugging**) to run.
8. Interact with the console window and observe results.

### 2. ASP.NET Web Forms Applications (Practicals 04A – 04C, 05B)
1. Open **Visual Studio**.
2. Click **Create a new project**.
3. Search for **ASP.NET Web Application (.NET Framework)** (C#) and click **Next**.
4. Target **.NET Framework 4.7.2** or **4.8**, select **Empty**, and check **Web Forms**.
5. In **Solution Explorer**, right-click the project &rarr; **Add &rarr; Web Form** (named `WebForm1.aspx` or `CookieDemo.aspx`).
6. Paste the `.aspx` markup into the source view and the `.aspx.cs` code into the code-behind view.
7. Right-click the `.aspx` page in Solution Explorer and select **Set As Start Page**.
8. Press **F5** to run the project in IIS Express.

### 3. ASP.NET Core MVC Applications (Practical 05A, 05C)
1. Open **Visual Studio** &rarr; **Create a new project** &rarr; **ASP.NET Core Web App (Model-View-Controller)**.
2. Target **.NET 8.0** / **.NET 6.0**.
3. In **Solution Explorer**, add the Model (e.g., `Models/Calculator.cs`), the Controller (e.g., `Controllers/HomeController.cs`), and the Razor View (e.g., `Views/Home/Index.cshtml`).
4. Press **F5** or `Ctrl+F5` to build and run in your browser.

### 4. Entity Framework Core CRUD with SQL Server (Practical 05D)
1. Open **Visual Studio** &rarr; **Create a new project** &rarr; **Console App (C#)** or **ASP.NET Core Web App**.
2. Open **Tools &rarr; NuGet Package Manager &rarr; Manage NuGet Packages for Solution**.
3. Search and install:
   * `Microsoft.EntityFrameworkCore.SqlServer`
   * `Microsoft.EntityFrameworkCore.Design`
4. Ensure your connection string in `appsettings.json` points to `(localdb)\mssqllocaldb`.
5. Open **Tools &rarr; NuGet Package Manager &rarr; Package Manager Console** and execute:
   ```powershell
   Add-Migration InitialCreate
   Update-Database
   ```
6. Press **F5** to run the program and perform CRUD operations.

### 5. ASP.NET Core Web API & Postman (Practicals 08B, 09A)
1. Open **Visual Studio** &rarr; **Create a new project** &rarr; **ASP.NET Core Web API**.
2. In Solution Explorer, add the API Controller (e.g., `Controllers/StudentController.cs` or `Controllers/MathController.cs`).
3. Press **F5** to start the API. Note the `https://localhost:<port>` address.
4. Open **Postman** (or browser) and send GET requests (e.g., `GET https://localhost:<port>/api/math/factorial/5`).

### 6. Progressive Web Applications (PWAs) (Practicals 06A – 07A, 08A, 10A)
1. Open the project in Visual Studio.
2. Ensure static file middleware (`app.UseStaticFiles()`) is enabled in `Program.cs`.
3. Verify that `manifest.json` and `service-worker.js` reside in `wwwroot/`.
4. Press **F5** to launch in Google Chrome or Microsoft Edge over `https://localhost` or `http://localhost`.
5. Open Chrome DevTools (**F12**) &rarr; **Application** tab:
   * Inspect **Manifest** (Identity, Icons, Theme Color).
   * Inspect **Service Workers** (Status, Offline checkbox for fallback testing).
   * Inspect **Storage / Cache Storage** for cached assets.

## Practical-Specific Setup Requirements

* **Unobtrusive Validation**: For Web Forms validation in Practical 04B, ensure `Web.config` includes `<add key="ValidationSettings:UnobtrusiveValidationMode" value="None" />` or that jQuery is registered in the ScriptManager.
* **AdRotator XML File**: For Practical 04C, verify that `XMLFile.xml` is located in the project root and that image files referenced in `<ImageUrl>` exist.
* **Notification Permissions**: For Practical 10A, browser security requires explicit user permission; click "Request Notification Permission" in the UI before testing push triggers.
