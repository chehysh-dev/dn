PRACTICAL 05B: DIFFERENT TYPES OF COOKIES (SESSION AND PERSISTENT COOKIES)
================================================================================

1. AIM / OBJECTIVE:
   To develop an ASP.NET application demonstrating the creation, storage, and retrieval of Session Cookies (in-memory) and Persistent Cookies (stored on client disk with explicit expiration dates).

2. REQUIREMENTS:
   * Visual Studio 2019 / 2022 / 2026
   * .NET Framework 4.7.2 / 4.8
   * IIS Express web server
   * Web browser with cookie inspection support

3. THEORY & CONCEPT:
   An HTTP Cookie is a small packet of state data stored on the client browser and transmitted to the server with every HTTP request.
   1. Session (Non-Persistent) Cookie: Stored only in browser RAM. It is deleted as soon as the user closes the browser session because no 'Expires' property is defined.
   2. Persistent Cookie: Contains an explicit expiration date ('Expires = DateTime.Now.AddDays(7)'). It is written to client hard disk storage and survives browser restarts until its expiry timestamp.
   Cookie APIs:
     - 'Response.Cookies.Add(HttpCookie)': Transmits 'Set-Cookie' HTTP response headers to the client.
     - 'Request.Cookies["Key"].Value': Reads incoming 'Cookie' HTTP request headers.

4. PROCEDURE / STEP-BY-STEP INSTRUCTIONS:
   1. Create an ASP.NET Web Application (.NET Framework).
   2. Add a Web Form named 'CookieDemo.aspx'.
   3. Place a TextBox (txtName), Save Button (btnSave), Show Button (btnShow), and an output Label (lblOutput).
   4. In 'btnSave_Click', create a session cookie without expiration and a persistent cookie with 'DateTime.Now.AddDays(7)'. Add both to 'Response.Cookies'.
   5. In 'btnShow_Click', read values from 'Request.Cookies' and format into 'lblOutput'.
   6. Run the application, type a username, click 'Save Cookie', then click 'Show Cookies'.
   7. Restart the browser and test 'Show Cookies' to see persistent cookie retention.

5. PROGRAM / COMPLETE SOURCE CODE:
----------------------------------------------------------------------
File: Practical-05B-Code.aspx.cs (CookieDemo.aspx.cs)
----------------------------------------------------------------------
using System;
using System.Web;

namespace CookieApplication
{
    public partial class CookieDemo : System.Web.UI.Page
    {
        protected void Page_Load(object sender, EventArgs e)
        {
        }

        protected void btnSave_Click(object sender, EventArgs e)
        {
            // Session Cookie (No expiration date set; deleted when browser closes)
            HttpCookie sessionCookie = new HttpCookie("SessionUser");
            sessionCookie.Value = txtName.Text;
            Response.Cookies.Add(sessionCookie);

            // Persistent Cookie (Expires in 7 days; persisted on client disk)
            HttpCookie persistentCookie = new HttpCookie("PersistentUser");
            persistentCookie.Value = txtName.Text;
            persistentCookie.Expires = DateTime.Now.AddDays(7);
            Response.Cookies.Add(persistentCookie);

            lblOutput.Text = "Cookies Saved Successfully";
        }

        protected void btnShow_Click(object sender, EventArgs e)
        {
            string sessionData = (Request.Cookies["SessionUser"] != null)
                ? Request.Cookies["SessionUser"].Value
                : "No Session Cookie Found";

            string persistentData = (Request.Cookies["PersistentUser"] != null)
                ? Request.Cookies["PersistentUser"].Value
                : "No Persistent Cookie Found";

            lblOutput.Text = "Session Cookie: " + sessionData +
                             "<br/>Persistent Cookie: " + persistentData;
        }
    }
}

9. TROUBLESHOOTING & TECHNICAL NOTES:
